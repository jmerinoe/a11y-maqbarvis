# Design: Platform deployment

## Context

Greenfield-to-online evolution. Current app is a static Vite SPA with browser-only persistence. Target: experience app + ranking kiosk online, shared backend, minimal Azure spend.

## Decisions (resolved with owner)

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Compute | Azure Function App (Consumption, Node 20, Linux) | Decoupled shared API; future experiences consume it; ~free at this volume |
| Topology | One new SWA, subroutes `/` + `/kiosko` | Single pipeline; kiosk build lands as subfolder of SWA artifact; hash routing needs no rewrite rules |
| Admin auth | Shared PIN via `X-Admin-Pin` header | Sufficient for workshop context; zero friction |
| Storage | Table Storage (existing Storage Account) | Pennies/month; partition-per-experience gives per-experience ranking for free |
| Ranking updates | Polling every ~15 s | Sufficient for ranking; cheaper and simpler than SignalR |
| Repo layout | Monorepo `apps/`, `api/`, `shared/` | One place for contracts; GHA deploys both apps |
| Anti-tamper | `X-Event-Key` embedded in client bundle | Stops casual forging; upgrade path = server-side session tokens |

## API design

Azure Functions v4 model (`@azure/functions`, `app.http`). One file per endpoint group:

- `src/functions/public.js` — `users` (POST), `results` (POST), `ranking` (GET), `experiences` (GET), `health` (GET)
- `src/functions/admin.js` — `admin/results` (GET list, POST add), `admin/results/{pk}/{rk}` (PATCH, DELETE), `admin/results` (DELETE reset)

Storage layer `src/lib/table.js` wraps `@azure/data-tables` `TableClient`:
- `ensureTables()` — `createTable` idempotent on startup
- `users` table: PartitionKey `'users'`, RowKey `normalizedName`, property `name`
- `results` table: PartitionKey `experienceId`, RowKey `${9999999999999 - endedAtEpoch}-${guid}` (inverted timestamp → newest first ordering)
- Result entity: `{ user, elapsedMs (Int32), startedAt, endedAt, result: 'completed' }`

Auth helpers `src/lib/auth.js`:
- `requireEventKey(req)` — compares `X-Event-Key` header to `EVENT_KEY` env → 401
- `requireAdminPin(req)` — compares `X-Admin-Pin` header to `ADMIN_PIN` env → 401/403

CORS: configured on the Function App (`ALLOWED_ORIGINS` → SWA hostname + `http://localhost:5173`).

## Experience app changes

- `src/api/client.js` — thin fetch wrapper: base URL from `import.meta.env.VITE_API_BASE_URL`, injects `X-Event-Key` from `VITE_EVENT_KEY`
- `session.js` — `registerUser` → POST `/users`; `saveResult` → POST `/results` with localStorage fallback queue (`faro-pending-results`) retried on ranking render
- `ranking.js` — fetch `GET /ranking?experienceId=`; fallback to local results if API down (marked as offline view)
- `.env.development` / `.env.production` handling via Vite env

## Kiosk app design

- Vite + vanilla JS (same conventions as experience), `base: '/kiosko/'`
- `src/api.js` — read-only client (ranking, experiences) + admin client (PIN header)
- `src/screens/presentation.js` — fullscreen table; rotation timer (10 s) cycles `experiences[]`; poll timer (15 s) refetches; `role="status"` polite updates; last-updated age display; offline state
- `src/screens/admin.js` — PIN gate → table of results (all fields, editable inline or via form), delete per row, add form, reset per-experience + global with confirm
- `src/main.js` — hash router: `#/` → presentation, `#/admin` → admin
- Panel branding via `panel-logo.jpg` copied to `apps/kiosk/public/images/`

## Data model

`results` table entity:
```
PartitionKey: experienceId
RowKey:       `${InvertedTicks}-${uuidv4().slice(0,8)}`
user:         string
elapsedMs:    Int32
startedAt:    Edm.DateTime (ISO)
endedAt:      Edm.DateTime (ISO)
result:       'completed'
```

`users` table entity:
```
PartitionKey: 'users'
RowKey:       normalizedName
name:         display name (trimmed)
createdAt:    Edm.DateTime
```

## Deployment

- `swa-deploy.yml` (auto-generated by Azure on SWA creation, then adjusted):
  `npm ci && npm run build` in `apps/experience` → `apps/experience/dist`;
  then `npm ci && npm run build` in `apps/kiosk` → copy `apps/kiosk/dist` to `apps/experience/dist/kiosko`;
  `app_location: apps/experience`, `output_location: dist`.
- `api-deploy.yml`: on `api/**` changes → `func azure functionapp publish` equivalent via `Azure/functions-action@v1`.
- Secrets in GitHub: `AZURE_FUNCTIONAPP_PUBLISH_PROFILE`, SWA token (auto).

## Testing strategy

- `api/tests/*.test.js` — Vitest with mocked TableClient: key/pin guards, ranking sort+top10, reset scoping, validation errors
- Experience: adapt existing session tests to mocked fetch; pending-queue fallback test
- Kiosk: structural tests — rotation logic, PIN gate, poll refresh, admin CRUD calls
- Total budget: keep existing 94 tests green + new coverage
